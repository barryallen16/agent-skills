# Writing Clearly

Goal: get ideas across simply and clearly. Not fancy words.

## Prerequisites

1. Want to write clearly.
2. Willing to work hard. Thinking is work.
3. Follow the guidelines below.

If a lovely/dramatic phrase comes, keep it only if it survives this test: "Does it detract from clarity?" If yes, cut it.

## Process

### 1. Outline before you start

- Write one point per card (one line per bullet).
- Group closely related points into piles.
- Order piles: what must come first to make the rest understandable? What is most important?
- Order points within each pile.
- Add intro + conclusion only after this.

### 2. Start where readers are

- Match their knowledge level. Don't write above it.
- Purpose is to explain, not to prove you're smarter.
- Never write down to a "12-year-old mentality" — that's insulting.

### 3. Avoid jargon

Replace insider terms with plain equivalents.

- Bad: "The biota exhibited a one hundred percent mortality response."
- Good: "All the fish died."

### 4. Use familiar word combinations

Prefer plain, spoken phrasing over formal abstraction.

- Bad: "We are endeavoring to construct a more inclusive society."
- Good: "We're going to make a country in which no one is left out."

Keep grammar correct — bad grammar is unclear (e.g. "John's father says he can't go out Friday" — who can't?).

### 5. Use first-degree words

Prefer words that bring an immediate image, no translation needed. Cut the rest.
