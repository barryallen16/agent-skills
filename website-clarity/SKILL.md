# Website Clarity

Use these instructions to audit or write landing pages and website hero sections.
A website converts visitors into users or customers.
Visual polish cannot rescue copy that fails to explain the product.
Traffic cannot fix a page that visitors do not understand.

## Integration with Unslop and Interaction Design

Always run this skill together with [unslop](../unslop/SKILL.md) and [interaction-design](../interaction-design/SKILL.md).
Messaging, visual design, and interactive states work together:
1. Audit and rewrite the messaging, target audience, proof points, and calls to action using the clarity heuristics below.
2. Run the `unslop` pass on the visual interface to tighten spacing, color, typography, layout, icons, details, and layout rhythm.
3. Run the `interaction-design` pass on interactive elements to establish button microinteractions, hover and active states, loading feedback, and reduced-motion support.
4. Deliver the clarified copy, polished layout, and interaction specifications together.

## The 5-Second Test

Assume visitors leave if they do not understand the page within five seconds.
If a page requires outside explanation, the copy has failed.

Every above-the-fold view must answer four questions immediately:

1. **What do you do?**
State the service or product in plain words.
Avoid metaphors, industry jargon, and vague claims.

2. **Who is it for?**
Name the target audience or describe their specific problem.
The visitor should recognize their own needs immediately.

3. **Why should I trust you?**
Provide credible evidence.
Use customer logos, review counts, hard data, certifications, or concise testimonials.

4. **What happens next?**
Provide one obvious primary action.
Use explicit button copy such as "Start Free Trial" or "Book a 15-Minute Call" instead of passive labels.

## Core Heuristics

- **One clear path.**
Give visitors a single obvious next step.
Remove secondary buttons, competing banners, and distracting links from the primary view.

- **Direct language.**
Describe the exact outcome the customer gets.
Vague slogans force visitors to guess.

- **Friction reduction.**
State price models, trial terms, or setup requirements upfront if ambiguity causes hesitation.

- **Immediate interactive feedback.**
Make interactive controls feel responsive by confirming pointer and keyboard input within 100ms.

## Audit Workflow

When asked to audit a website, run through these steps:

1. Read the current headline, subheadline, call to action, and trust elements.
2. Grade the four questions: pass, weak, or fail.
3. List elements causing distraction, friction, or confusion.
4. Execute the [unslop](../unslop/SKILL.md) audit on layout, spacing, typography, and styling.
5. Execute the [interaction-design](../interaction-design/SKILL.md) audit on call-to-action buttons, hover/active states, and form inputs.
6. Provide a rewritten hero section:
   - Headline (clear statement of what you do)
   - Subheadline (who it is for and the key outcome)
   - Trust indicator (specific proof point)
   - Call to action (button copy and destination)
   - Interaction states (hover, press, loading feedback, and timings under 150ms)
7. Apply the visual unslopping passes to produce the final, craft-focused result.
