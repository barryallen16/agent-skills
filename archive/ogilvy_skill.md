# Ogilvy Writing

Source: David Ogilvy 1982 memo "How to Write" via https://www.wordsthatsing.com.au/post/how-to-write-ogilvy
Premise: `People who think well, write well. Good writing is not a natural gift. You have to learn to write well.`

Goal per page: connect, engage to keep reading, inspire action.

## The 10 rules

1. Read good writing 3x. Ogilvy: Roman-Raphaelson `Writing That Works`. Takeaway: reading habits = writing quality. Absorb voice/tone, then spot own errors.
2. Write like you talk. Natural, casual, everyday. If you wouldn't say it, don't write it.
3. Short everything. Short words, sentences, paragraphs. Reading costs energy; deliver value fast. Cut anything serving writer not reader.
4. No jargon. Never `reconceptualize, demassification, attitudinally, judgmentally`. Big words = pretentious, confuse, disconnect. Say little with small words.
5. Max 2 pages. Never write more than necessary. If shortening keeps meaning, shorten.
6. Check quotations. Facts/quotes shape perception. Double-check in fake-news age. Readers trust you - be honest.
7. Sleep on it. Never send same day. Read aloud next morning, then edit. Fresh eyes catch what intention hid.
8. Get a colleague. If important (and if your name is on it, it is important), second eyes improve it. Writing = credibility, forever online.
9. State the want. Before sending, make crystal clear what recipient must do. No dead-end `now what?` messages.
10. Want ACTION? Don't write. Go tell them face-to-face. Smile/handshake + emotion beats text for trust and decisions.

## Process

1. Define one action reader must take.
2. Draft naturally, short, jargon-free, <=2 pages.
3. Verify every quote/fact.
4. Sleep, read aloud, edit.
5. If important, colleague pass.
6. Confirm action is explicit. If action truly matters, deliver in person.

## Fail checks

- Would Ogilvy call a word pretentious-ass? Cut it.
- Can a sentence be shorter without loss? Shorten.
- Reader knows exact next step? If no, rewrite close.
